wealthfolio/wealthfolio9,582 stars · +32 today

Wealthfolio

A local-first app that tracks your investments and net worth, for people who don't want their money data sitting in someone else's cloud.

Replaces Monarch Money Core$99.99 a year

Monarch Money Core is $99.99 a year. Wealthfolio tracks your portfolio and spending on your own device, with no account and no cloud database. The README says manual tracking and CSV import are free forever. Automatic syncing with your brokerage needs Wealthfolio Connect, which is their own subscription and it's optional. So you type in your trades yourself or you end up paying for another plan anyway. 109 people have contributed and the last commit was today.

Try it

Run it next to Monarch for a month. If CSV imports are enough for your accounts, cancel the subscription.

Keep paying if you want your accounts to sync by themselves and don't want to add another subscription for it.

Twenty

An open source CRM that technical teams build and change in code, made for people who are leaving Salesforce.

Also by twentyhq: favicon 446. 4 public repos, 61,647 stars in all.

Replaces Salesforce Sales Cloud Starter Suite$25 per user a month

Salesforce Starter Suite costs $25 per user a month. Twenty is an open source CRM, and the README says it's for technical teams who define their objects and fields as code. There's a hosted cloud, or you can self-host and run the server yourself. 807 people have contributed and the last commit was today. The catch is that it's a CRM you build, so somebody on the team has to write that code.

Try it

Try Twenty next to Salesforce if there's a developer on the team who can set it up for the way you sell.

Keep paying if nobody on your team wants to set up a CRM and keep it running.

Firecrawl

Open source scraper and search API that pulls web pages and gives back clean data an AI agent can use.

Replaces Firecrawl Cloud Hobby$16 a month

Firecrawl Cloud Hobby is $19 a month, or $16 a month if you pay for the year. The code is open source and you can host it yourself, and then it's your server and you keep it running. The README says it handles proxies and rate limits for you. It doesn't say how much of that still works when you host it yourself. It got 795 stars today. A normal day is about 215. Try it

If you already run servers, try it next to Firecrawl Cloud, and once it handles the sites you scrape you can cancel Firecrawl Cloud.

Keep paying if you don't want to run your own scraping server and fix it yourself.
