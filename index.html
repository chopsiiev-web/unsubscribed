RustDesk

An open-source remote desktop app you can run on your own server, for people who use TeamViewer to reach other computers.

Replaces TeamViewer TeamViewer Premium49,63 € a month

TeamViewer Premium costs 49,63 € a month, billed yearly.

RustDesk lets you control another computer too, and the README says it works out of the box.

It got 174 stars today, and a normal day is closer to 59.

You can use their relay server or run your own, and if you run your own then the server and the upkeep are on you.

When your relay breaks there's nobody to call.

Cancel

You can cancel TeamViewer if you're fine with their relay or don't mind running your own server.

Keep paying if you want a vendor you can call when a session won't connect.

EdgeEver

An open-source note-taking app for Evernote users who want to keep their notes on their own server.

Replaces Evernote Starter€6.65 a month

Evernote Starter is €6.65 a month. EdgeEver keeps the same three-pane notes layout, and the README says it runs free inside Cloudflare's free quotas.

You can also run it on your own VPS or NAS with Docker.

You have to set it up yourself, and if sync stops working there's no support to write to.

So you'd be fixing it on your own. Someone pushed a commit today, so the project is still being worked on.

Try it

If setting up a Cloudflare account or Docker doesn't bother you, EdgeEver is worth trying next to Evernote.

Keep paying if you want someone else to keep the sync working.
