appwrite/appwrite58,564 stars · +51 today

Appwrite

An open-source backend with auth and databases for developers and their coding agents, and you can use the hosted version or run it yourself.

Replaces Supabase Pro$25 a month

Supabase Pro starts at $25 a month.

Appwrite says in its README that it covers the same kind of backend in one place, and you can self-host it on infrastructure you control.

The problem is you run the server and do the Docker upgrades yourself, and when it breaks nobody picks up.

The project is alive, it has 556 contributors and someone committed today. It got 51 stars today. On a normal day it's about 21.

Try it

If Docker doesn't bother you, run Appwrite next to Supabase on your next project and cancel once it holds up.

Keep paying if your app already runs on Supabase and you don't want to run your own server.

zhouxiaoka/autoclip13,183 stars · +640 today

AutoClip

A desktop app that cuts long videos like podcasts into short clips, for anyone who posts shorts.

Replaces Opus Clip Starter$15 a month

AutoClip got 640 stars today. Most days it gets about 26. It runs on your own computer and the software is free.

But the README says the cloud models it uses are billed by usage, so running it still costs something.

Opus Clip's Starter plan is $15 a month, and the pricing page only lets you pay monthly.

Try it

Run AutoClip alongside Opus Clip for a few weeks before you cancel anything.

Keep paying if you want one monthly bill and somebody else to deal with it when it breaks.

FlashML-org/FreeVideo4,246 stars · +209 today

FreeVideo

A tool that makes AI videos on your own graphics card, for creators who don't want to pay to rent one.

Replaces Runway Standard$12 a month

Runway Standard costs $12 a month if you pay for the year.

FreeVideo runs MiniMax H3 on your own computer, and the README says 8 GB of VRAM can be enough.

But then the hardware is yours to buy and keep running, and when it breaks there's nobody to call. It got 209 stars today.

On a normal day it gets about 61. A small team pushed a commit yesterday.

Try it

If you already have a decent GPU, try it next to Runway.

Keep paying if your graphics card can't run it.
