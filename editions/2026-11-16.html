alibaba/open-code-review52,753 stars · +946 today

Open Code Review

Alibaba's command-line tool that has an LLM review your Git diffs, for teams that want code review done automatically.

Replaces CodeRabbit Essentials$24 per user a month

CodeRabbit Essentials costs $24 per developer a month if you pay for the year. For a team of ten that's $240 every month.

Open Code Review is a CLI that reads your Git diffs, and an LLM agent writes review comments on the exact lines.

The README says Alibaba used it internally first. You still need your own model endpoint and you pay for the tokens yourself.

They also say recall is lower on purpose.

The repo has 222 contributors and someone committed today.

Cancel

I think a team that's fine with a CLI and already pays for an LLM API doesn't need to keep paying for CodeRabbit.

isair/jarvis2,309 stars · +26 today

Jarvis

A desktop AI assistant you talk to by voice, and the dictation and chat run on your own computer, so it stays private.

Replaces Wispr Flow Pro$12 per user a month

Wispr Flow Pro is $12 per user a month. For a team of ten that's $120 every month.

Jarvis is a local voice assistant and its description calls it a free Wispr Flow alternative with dictation.

Dictation is only one of a lot of features in it.

The README says the speech and chat models run locally when you use a local model server.

So you have to set that up and keep it running.

Eleven people have worked on it and the last commit was today.

Try it

Before you cancel Wispr Flow, use them side by side for a bit.

This one is mostly an assistant, and the dictation is the smaller part of it.

FujiwaraChoki/supoclip3,288 stars · +103 today

SupoClip

Open-source tool that cuts long videos like podcasts and streams into vertical clips, for people who post shorts.

Replaces OpusClip Starter$15 a month

SupoClip's README starts with "Fuck OpusClip." OpusClip's Starter plan is $15 a month.

You give SupoClip a long video, it picks the moments it scores as most viral and cuts them into vertical clips with subtitles.

You run it yourself with Docker Compose on your own hardware, and the README says there's no usage limit then.

If you don't want to set it up there's a hosted version too. Eight people have worked on it and the last commit was today.

Cancel

If you can run Docker Compose, you can cancel OpusClip Starter.

Mailflare

Self-hosted email for teams who want mail on their own domain, with calendar and file storage in the same place.

Replaces Google Workspace Starter€6.80 per user a month

Google Workspace Starter is €6.80 per user a month.

Mailflare is self-hosted email and calendar on your own domain, and the README says it runs on Cloudflare or Docker.

You still pay for a sending service like Resend or Amazon SES, and for somewhere to keep the files.

It has 54 contributors and the last commit was today.

Cancel
