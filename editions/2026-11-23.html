appwrite/appwrite58,614 stars · +121 today

Appwrite

An open-source backend you can host yourself, with auth and a database for developers and the coding agents they use.

Also by appwrite: sdk-for-react-native 4,241, awesome-appwrite 1,092, pink 522. 165 public repos, 71,788 stars in all.

Replaces Supabase Pro$25 a month

Supabase Pro starts at $25 a month, and that covers the first project. Appwrite does the same backend job, and the README says you can self-host it on infrastructure you control. If you go that way, you run the server and do the upgrades yourself. Somebody pushed a commit today, and it's getting a lot more stars than it usually does.

Cancel

If you can run Docker and keep a server patched, you can cancel Supabase Pro.

Keep paying if you want someone else to run the database and answer the pager.

anomalyco/opencode228,711 stars · +189 today

OpenCode

An open source AI coding agent for developers who want to install it and run it themselves.

Also by anomalyco: sst 26,460, opentui 13,891, hex 8,198. 77 public repos, 314,194 stars in all.

Replaces Claude Code (Claude Pro) Pro$17 a month

Claude Pro is $20 a month, a bit less if you pay for the year. OpenCode is a coding agent you install yourself, with one command or through a package manager. There's also a desktop app, but the README still calls it beta. Updates are on you, and if it breaks there's nobody to call. On the other hand 1,100 people have worked on it and the last commit was today. It's made by the people behind sst.

Cancel

If you're paying for Claude Pro mostly to use Claude Code and you don't mind installing things yourself, you can cancel it.

Keep paying if you want someone else to fix the coding tool when it breaks.

FlashML-org/FreeVideo4,499 stars · +212 today

FreeVideo

A self-hosted tool that makes AI videos on your own graphics card, for creators tired of cloud video credits.

Also by FlashML-org: FreeToken 17,688, flashlib 604. 6 public repos, 22,906 stars in all.

Replaces Runway Standard$12 a month

FreeVideo is from the team that made FreeToken. It runs the MiniMax H3 model on your own computer, and the README says 8 GB of VRAM is enough. Runway Standard is $12 a month if you pay for the year. To use this one you need a card with that much memory, and if something goes wrong you have to sort it out yourself. It got 212 stars today, a lot more than it usually gets.

Try it

If you have a decent GPU, try FreeVideo next to Runway. It's only a couple of months old, so don't cancel Runway yet.

Keep paying if there's no decent graphics card, or if you need support when things go wrong.
