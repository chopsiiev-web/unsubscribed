Arcane

A self-hosted web app for managing Docker containers, and anyone who runs Docker can use it.

Replaces Portainer Business Edition Starter$1,045 a year

Portainer Business Edition's Starter plan is $1,045 a year. Arcane does Docker management for free, under a BSD-3-Clause license.

It's self-hosted, so running it and keeping it updated is on you, and nobody's on call when it breaks.

It picked up 654 stars today, which is a lot more than it usually gets.

A hundred people have worked on it, and the README says main is now the v3 version.

Cancel

If you pay for Portainer Starter just to manage your own Docker hosts, you can cancel it.

Keep paying if you need a vendor to call when something breaks.

dograh-hq/dograh6,169 stars · +13 today

Dograh

Open-source voice AI you host on your own servers, for teams building phone and voice agents.

Replaces Vapi Core$29 a month

Vapi's Core plan is $29 a month. Dograh is a voice agent platform you host yourself, and it has a visual workflow builder.

The README says it's free to self-host and it starts with one Docker command.

You still bring your own keys for the speech and language models, and you pay those providers yourself.

If a live call breaks, you're the one fixing it. It has 72 contributors and the last commit was yesterday.

Try it

Before you move your phone lines off Vapi, put a few real calls through Dograh and see how it does.

Keep paying if your agents take customer calls and you don't have time to look after a server.

anomalyco/hex7,217 stars · +198 today

Hex

A dictation app that runs locally and types what you say into any text field, on Mac, Windows or Linux.

Replaces Wispr Flow Pro$12 per user a month

Wispr Flow Pro costs $12 per user a month. Hex runs on your own computer.

You talk, it turns that into text on the device and pastes it where your cursor is.

The README says nothing leaves the computer once the speech model is downloaded the first time. It's made by the team behind opencode.

It got 198 stars today. Usually it's around 59 a day.

The project is still young and the experimental parts are in a Labs section. If something breaks, you'll probably have to sort it out yourself.

Try it

Run Hex next to Wispr Flow for a week before you cancel anything.

Keep paying if a support line matters for the day dictation breaks.
