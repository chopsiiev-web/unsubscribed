Appwrite

Open-source backend with auth and databases, for developers and the coding agents they build with.

Replaces Supabase Pro$25 a month

Supabase Pro starts at $25 a month. According to the README, Appwrite runs as a managed cloud or self-hosted on your own infrastructure.

And the self-hosted route is where the money is saved.

Then the server is yours and the upgrades are yours, and when it breaks there's nobody to call.

The project has been around a long time and 556 people have contributed. Last commit was today.

It got 52 stars today, and a normal day is about 21.

Cancel

If you're fine running Docker on your own server, you can cancel Supabase.

Keep paying if you want someone else to deal with the backend when it goes down.

anomalyco/opencode228,158 stars · +249 today

OpenCode

An open source AI coding agent, and you can run it in the terminal or install it as a desktop app.

Replaces Claude Code Pro$17 a month

OpenCode is from the team behind sst. 1,097 people have contributed to it and the last commit was today.

It installs with one command. There's also a desktop app, but that's still in beta.

Claude Code Pro is $20 a month. Paid yearly it comes down to $17. With OpenCode you run it and keep it updated yourself.

And the README excerpt doesn't say which model it talks to or what that model costs.

Try it

Run OpenCode next to Claude Code before you cancel anything, and drop the subscription once you've seen what the model bill actually comes to.

Keep paying if you want someone else to look after the tool and pick up when it breaks.

AutoClip

An open-source desktop app that cuts long videos into short clips, for people who post on TikTok and Douyin.

Replaces Opus Clip Starter$15 a month

Opus Clip Starter costs $15 a month.

AutoClip is free on GitHub, and you paste a link and it renders the clip on your own computer.

It still calls cloud models, and the README says those are billed by use.

It picked up 983 stars today, a lot more than it usually gets.

Try it

Run AutoClip alongside Opus Clip for a few weeks, and cancel only after that.

Keep paying if you want one fixed bill and someone to call when it breaks.

FreeVideo

An app that runs the MiniMax H3 video model on your own computer, for people making AI videos.

Replaces Runway Standard$12 a month

Runway Standard is $12 a month if you pay for the year.

FreeVideo makes AI videos on your own computer, and the README says 8 GB of VRAM is enough.

So you need a graphics card like that, and you run it yourself, and when it breaks there's nobody to call.

It got 39 forks today. On a normal day it's around 7. Last commit was yesterday.

Try it

If you have a good graphics card, try FreeVideo next to Runway.

Keep paying if there's no strong graphics card on your desk or you don't want to run anything yourself.
