Stalwart

An open-source mail and calendar server you run on your own machines, for teams who'd rather keep their email off someone else's servers.

Replaces Google Workspace Starter€6.80 per user a month

Google Workspace Starter costs €6.80 a user per month. For a team of ten that's €68.

Stalwart is a mail server you run yourself, and the README says it handles all the common mail protocols and calendars too.

When it breaks there's nobody to call, you fix it yourself, and with a mail server that's real work. The project does look well kept.

57 people have worked on it. The last commit was two days ago.

Try it

If running your own server doesn't scare you, try Stalwart alongside Workspace for a while. Move the team over once it holds up.

Keep paying if nobody on your team wants to look after a mail server.
