n8n

A workflow automation tool with a fair-code license that you can host on your own server, for people who connect their apps with Zapier.

Also by n8n-io: self-hosted-ai-starter-kit 15,376, nod 2,422, n8n-docs 1,855. 42 public repos, 235,220 stars in all.

Replaces Zapier Professional$19.99 a month

Zapier Professional starts at $19.99 a month. n8n does the same job, connecting your apps on a visual canvas, and the README says you can write JavaScript or Python when the blocks aren't enough. If you self-host it, that means Docker and a server you keep alive yourself. The project is busy and the last commit was today. It got 315 stars today, which is about four times a normal day. When it breaks there's nobody to call, and that's a fair reason to stay on Zapier.

Cancel

If you can run Docker and don't mind looking after a server, you can cancel Zapier.

Keep paying if you want your automations to run without setting up a server yourself.

stalwartlabs/stalwart16,021 stars · +28 today

Stalwart

An open-source mail and calendar server you run on your own machines, for teams who'd rather keep their email off someone else's servers.

Also by stalwartlabs: jmap-server 601, mail-parser 483, smtp-server 481. 31 public repos, 19,212 stars in all.

Replaces Google Workspace Starter€6.80 per user a month

Google Workspace Starter costs €6.80 a user per month. For a team of ten that's €68. Stalwart is a mail server you run yourself, and the README says it handles all the common mail protocols and calendars too. When it breaks there's nobody to call, you fix it yourself, and with a mail server that's real work. The project does look well kept. 57 people have worked on it. The last commit was two days ago.

Try it

If running your own server doesn't scare you, try Stalwart alongside Workspace for a while. Move the team over once it holds up.

Keep paying if nobody on your team wants to look after a mail server.
