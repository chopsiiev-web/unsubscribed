appwrite/appwrite58,477 stars · +50 today

Appwrite

An open-source backend for developers and AI agents building apps, and you can host it yourself or use the managed version.

Also by appwrite: sdk-for-react-native 4,241, awesome-appwrite 1,092, pink 522. 164 public repos, 71,649 stars in all.

Replaces Supabase Pro$25 a month

Supabase Pro starts at $25 a month. Appwrite does the same backend job, and the README says you can self-host it on your own infrastructure. Then the server and the upgrades are yours to run, and when it breaks there's nobody to call. 556 people have contributed and the last commit was today. It got 50 stars today, and a normal day is about 21. If your app is already live on Supabase, moving the auth and the data over is real work.

Try it

Try Appwrite on the next project before cancelling Supabase. It has been around long enough to replace it.

Keep paying if your app already runs on Supabase and you don't want to look after a server yourself.

OpenCode

An open source AI coding agent for developers that you install from the command line, and there's also a desktop app in beta.

Also by anomalyco: sst 26,457, opentui 13,876, hex 7,870. 77 public repos, 313,297 stars in all.

Replaces Claude Code (Claude Pro) Pro$17 a month

Claude Pro costs $20 a month. If you pay for the whole year it comes to $17.

OpenCode is an open source coding agent. You install it with npm or Homebrew and run it on your own machine, so you do the updates yourself, and if it breaks there's no support to call. The README excerpt doesn't say which models it works with, so check that before anything else.

It's made by the team behind sst. It has 1,098 contributors and somebody pushed a commit today.

Try it

Before you cancel Claude Code, run OpenCode next to it for a week. The project is alive and has plenty of people working on it.

Keep paying if you want one subscription that works and you don't want to install or maintain anything.

AutoClip

An open-source desktop app for creators that cuts long podcasts and interviews into short clips.

Also by zhouxiaoka: autoclip_mvp 1,271. 4 public repos, 13,939 stars in all.

Replaces Opus Clip Starter$15 a month

Opus Clip Starter is $15 a month. With AutoClip you paste a link and it renders the clip on your own machine. The software is free, and the README says the cloud models are billed by usage, so you still pay as you go.

It got 689 stars today. On a normal day it gets about 25. Six people work on it and the last commit was today.

A flat price is easier to budget. And when AutoClip breaks there's nobody to call.

Try it

Run AutoClip next to Opus Clip for a month and see what the model bill comes to.

Keep paying if you want one fixed price and someone to call when it breaks.

FlashML-org/FreeVideo4,081 stars · +410 today

FreeVideo

Makes AI videos locally on your own graphics card, for anyone tired of paying for credits.

Also by FlashML-org: FreeToken 17,539, flashlib 604. 6 public repos, 22,336 stars in all.

Replaces Runway Standard$12 a month

Runway Standard is $12 a month if you pay for the year. FreeVideo runs the MiniMax H3 model on your own machine, and the README says it can work with as little as 8 GB of VRAM. You need your own card, though, and if something breaks there's nobody to call. It got 410 stars today. On a normal day it gets about 59. The last commit was yesterday.

Try it

If you already have a gaming GPU, try it next to Runway. It's only a couple of months old, so don't cancel Runway yet.

Keep paying if there's no decent graphics card in the machine, or if running and updating the software yourself sounds like a chore.
